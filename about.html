About MC Skin Workshop

MC Skin Workshop is a Minecraft skin tool project built to make skin creation, editing, recolouring, reshading and sharing easier.

The goal is to eventually combine useful Minecraft skin tools into one clean website, instead of needing to jump between different editors, image programs and skin sites.

Current features include basic skin upload, preview and validation for modern 64x64 skins and legacy 64x32 skins.
